# 0. FUNÇÃO DESTE DOCUMENTO

Este arquivo é a FONTE CENTRAL DE VERDADE do desenvolvimento do site da
Vinícola Terra dos Ventos.

Antes de alterar qualquer arquivo do projeto:

1. Leia este documento integralmente.
2. Inspecione os arquivos atuais somente onde necessário.
3. Não redesenhe o projeto do zero.
4. Não simplifique o template Laon.
5. Não substitua tecnologias ou bibliotecas sem necessidade comprovada.
6. Não invente informações comerciais, técnicas ou operacionais.
7. Preserve o máximo possível da riqueza visual, espaçamentos, composição,
   responsividade e componentes do template original.
8. Faça alterações progressivas e rastreáveis.
9. Ao concluir uma etapa, atualize `TDV_STATUS.md`.
10. Não altere páginas que não façam parte da etapa atual sem necessidade.

PRINCÍPIO MÁXIMO:

> INTEGRAR A TERRA DOS VENTOS AO LAON.
> NÃO REDESENHAR O LAON PARA PARECER OUTRO TEMPLATE.

Quando houver conflito entre "deixar mais moderno" e preservar a riqueza
visual/estrutura do Laon, preserve o Laon.

Quando houver conflito entre preencher um espaço e inventar conteúdo,
não invente: deixe o bloco preparado e oculto.

mantenha a poesia no título e devolva clareza no texto explicativo e no CTA.

# 1. OBJETIVO DO SITE

O site não deve apresentar a Terra dos Ventos simplesmente como
"uma vinícola bonita onde se pode degustar vinho".

O site deve transformar os elementos já existentes da marca em um universo
coeso:

- vento
- terra
- pedra
- videira
- café
- Serra dos Encontros
- Portugal
- vinho
- mesa
- paisagem
- hospitalidade
- memória
- pertencimento
- experiências

Tese central:

A Terra dos Ventos é uma casa de encontros onde uma paisagem restaurada
se transforma em vinho, mesa, percurso e memória.

O vinho é uma porta de entrada para a marca.
O Wine Bar é outra.
Os mirantes são outra.
A vindima é outra.
A história da propriedade é outra.

O visitante deve primeiro SENTIR a marca e, logo depois,
entender claramente COMO visitá-la, reservar, conhecer seus vinhos
ou participar de uma experiência.

A Terra dos Ventos é uma vinícola boutique de Espírito Santo do Pinhal,
na Serra dos Encontros.

Não é uma marca baseada em volume.

A percepção deve vir de:

- cuidado
- pequena escala
- autoria
- história
- origem
- serviço
- hospitalidade
- paisagem
- experiência

- premium

- sofisticado

espaçamento, texto e experiência.

Direção:

- premium, mas não fria
- poética, mas não confusa
- regional, mas não simplória
- portuguesa, mas não caricata
- sofisticada, mas humana

# 10. TIPOGRAFIA

> ATUALIZAÇÃO DE DIRETRIZ — 07/10/2026
>
> A diretriz anterior de preservar a fonte de corpo do template Laon está revogada.
>
> O projeto deve utilizar os webfonts oficiais fornecidos pela marca:
>
> - TDV Times — Regular
> - TDV Times — Italic
> - TDV Times — Bold
> - TDV Times — Bold Italic
> - Eyesome Script — Regular
>
> A família Times passa a ser a fonte estrutural do site, incluindo corpo,
> navegação, títulos, botões e informações técnicas.
>
> Eyesome Script é a fonte expressiva da marca e deve ser utilizada
> seletivamente em palavras ou pequenas expressões de caráter poético.
>
> A substituição das famílias tipográficas NÃO implica simplificar ou
> redimensionar globalmente o template Laon. A hierarquia e os pesos
> visuais do template devem ser preservados e reinterpretados com os
> pesos reais disponíveis nos webfonts da marca.

A identidade determina:

Títulos e subtítulos:
Times New Roman

Acentos manuscritos:
Eyesome Script

Corpo:
preservar inicialmente a fonte de corpo do Laon, atualmente baseada
em Lato, porque mantém legibilidade e preserva a personalidade do template.

Não transformar TODO o site em Times New Roman.

Não utilizar Eyesome Script em:

- corpo de texto
- navegação
- botões
- formulários
- ficha técnica
- textos pequenos
- informações operacionais

Eyesome deve aparecer como ACENTO.

Exemplo:

Feita de <span class="tdv-script">mistérios</span>.

Do vento ao <span class="tdv-script">vinho</span>.

Soprada pelo vento, feita de <span class="tdv-script">segredos</span>.

Limitar normalmente a uma palavra ou pequena expressão manuscrita
em cada composição.

ATENÇÃO:
Antes de disponibilizar os arquivos locais das fontes diretamente na web,
confirmar licença de uso web quando aplicável.

## ATUALIZAÇÃO — LOGOTIPOS SVG

As versões PNG/JPG anteriormente mencionadas deixam de ser fonte de
implementação para a interface web.

Utilizar exclusivamente:

- `images/svg/logotipo-horizontal-cor.svg`
- `images/svg/logotipo-vertical-cor.svg`
- `images/svg/icon-cor.svg`
- `images/svg/logotipo-horizontal-branco.svg`
- `images/svg/logotipo-vertical-branco.svg`
- `images/svg/icone-branco.svg`

Regra de seleção:

- fundo claro → versão colorida;
- fundo escuro/fotográfico → versão branca;
- header → preferência pela versão horizontal;
- assinatura institucional → horizontal ou vertical conforme composição;
- marca reduzida/favicon → símbolo.

O logotipo inserido no HERO PRINCIPAL deve possuir:

`max-height: 4em;`

4em é o limite máximo, não um tamanho obrigatório.
Se 3–3.5em produzir melhor equilíbrio com o H1, utilizar o tamanho menor.

Nunca distorcer a proporção do SVG e nunca modificar suas cores via CSS.

A orientação anterior de gerar cópias web a partir dos PNGs está revogada
para a interface. O pacote raster e o MOV continuam apenas como arquivo
de marca, fora do front.

O pacote de marca contém versões coloridas, pretas e brancas.

Referências visuais dos PNGs fornecidos:

1 = composição principal vertical colorida
2 = composição horizontal colorida
3 = símbolo colorido

4 = composição principal preta
5 = composição horizontal preta
6 = símbolo preto

7 = composição principal branca
8 = composição horizontal branca
9 = símbolo branco

Usos preferenciais:

Header escuro:
versão horizontal branca.

Footer escuro:
versão principal ou horizontal branca.

Fundos claros:
versão horizontal colorida.

Favicon / elemento reduzido:
símbolo.

Não redesenhar o logo.
Não recriar tipografia do logo com HTML.
Não alterar proporções.
Não alterar cores internas.
Não aplicar sombras.

Os PNGs fornecidos possuem resolução muito alta.

Não carregar diretamente no site imagens de logo com milhares de pixels
se uma versão otimizada puder ser gerada.

Criar cópias web otimizadas preservando transparência e proporção.

Existe também um arquivo MOV de logo animado.
NÃO utilizá-lo automaticamente no site.
Tratar como recurso opcional a ser validado posteriormente.
